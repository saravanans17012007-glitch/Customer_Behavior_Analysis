# Customer_Behavior_Analysis
Customer Shopping Behavior Analysis

Overview

This project analyzes customer shopping behavior to understand purchasing patterns, customer preferences, subscription trends, and discount usage. The goal is to turn raw shopping data into useful business insights using data analytics tools.

Dataset

The dataset contains customer shopping information, including:

- Customer ID, age, and gender
- Items purchased and product categories
- Purchase amount and location
- Size, color, and season
- Review ratings
- Subscription status
- Shipping type
- Discount and promo code usage
- Previous purchases and payment method

Tools and Technologies

- Python: Data analysis and cleaning
- Pandas and NumPy: Data manipulation
- Matplotlib and Seaborn: Data visualization
- SQL / MySQL: Business queries and analysis
- Power BI: Interactive dashboard
- Gamma: Project presentation

Project Workflow

1. Data Loading: Import the customer dataset into Python using Pandas.
2. Exploratory Data Analysis (EDA): Understand the dataset, data types, distributions, and purchasing patterns.
3. Data Cleaning: Check missing values, duplicates, inconsistent data, and unnecessary columns.
4. Database Analysis: Load the cleaned data into MySQL and write SQL queries to answer business questions.
5. Dashboard Development: Build a Power BI dashboard to present important metrics and trends.
6. Reporting: Summarize the findings and business recommendations.
7. Presentation: Create a project presentation using Gamma.

Business Questions

- Which products and categories are purchased most often?
- Do subscribed customers spend more than non-subscribers?
- Which products have the highest discount usage?
- Which customer groups contribute most to revenue?
- What are the major shopping and purchasing trends?

How to Run

1. Download or clone this GitHub repository.

2. Install Python and Jupyter Notebook.

3. Install the required libraries:
   
   pip install pandas numpy matplotlib seaborn

4. Open the Jupyter Notebook.

5. Update the dataset path in the notebook to match your computer.

6. Run the cells in order.

7. Use the SQL query file to reproduce the database analysis.

8. Open the Power BI report to explore the dashboard.
